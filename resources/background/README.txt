===============================================
기본 배경화면 폴더 (Default Backgrounds)
===============================================

이 폴더는 기본 배경화면 폴더입니다.
언어 선택 기능을 사용하지 않거나, 언어별 폴더에 파일이 없을 때 사용됩니다.

[언어별 배경을 사용하려면]
- 한국어: background_ko 폴더에 이미지 추가
- English: background_en 폴더에 이미지 추가

[파일명 규칙]
화면번호.확장자 (예: 0.png, 1.jpg, 6.mp4)

[화면 번호]
0 = 시작 화면 (Splash)
1 = 카메라 화면
2 = 텍스트 입력 화면
3 = QR 코드 화면
4 = 프레임 선택 화면
5 = 처리 중 화면
6 = 완료 화면
