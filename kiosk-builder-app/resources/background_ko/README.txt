===============================================
한국어 배경화면 폴더
===============================================

이 폴더에 한국어 화면용 배경 이미지를 넣어주세요.

[파일명 규칙]
화면번호.확장자

[화면 번호]
0 = 시작 화면 (Splash)
1 = 카메라 화면
2 = 텍스트 입력 화면
3 = QR 코드 화면
4 = 프레임 선택 화면
5 = 처리 중 화면
6 = 완료 화면

[지원 확장자]
.mp4 (동영상), .gif (애니메이션), .png (이미지), .jpg (이미지)

[예시]
0.png -> 한국어 시작화면 배경
1.jpg -> 한국어 카메라화면 배경

[참고]
파일이 없는 화면은 기본 배경(background 폴더)이 사용됩니다.
